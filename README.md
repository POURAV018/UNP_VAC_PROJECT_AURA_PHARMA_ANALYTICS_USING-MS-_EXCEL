# UNP_VAC_PROJECT_AURA_PHARMA_ANALYTICS_USING_MS_EXCEL

An end-to-end company data analysis pipeline built in collaboration with UNP Education, covering data wrangling, exploratory data analysis (EDA), statistical hypothesis testing, and interactive visualization across 7,000+ records. Engineered using EXCEL, this repository includes structured reproducible cleaning scripts, and analytical dashboards designed to identify key operational bottlenecks and for data-driven decision-making.
